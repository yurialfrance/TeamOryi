# Sipnayan — Math na Masaya

**Duolingo-style math learning in Taglish, aligned to DepEd MATATAG & CHED, with an offline AI tutor.**
Built by **TeamOryi** for the **AppBuildersPH Hackathon 2026**.

Learners climb a stage-by-stage path from Grade 1 to college, earn XP, keep a daily streak, and protect their hearts —
while Pipo the pig gives hints, explains mistakes, and writes local word problems using an AI model that runs
**on the device itself**. No account, no server, no data leaves the phone.

**Live app:** https://yurialfrance.github.io/TeamOryi/

## What runs locally

Everything the learner does runs **on the device**, and keeps working in **airplane mode** after the first visit:

- **Lessons** — every question is generated by code on the device (24,000+ checked in tests), and answers are graded by code
  (`2(x+3)` = `2x+6`, `0.5` = `1/2`, `x = 5` = `5`).
- **Sipnayan Calculator** (`src/engine/solver.ts`) — arithmetic, fractions, algebra, linear/quadratic equations, limits,
  derivatives and integrals, with step-by-step work and graphs.
- **Pipo AI** — hints, "Bakit mali?" explanations, tutor chat, and *Kwento ni Pipo* word problems, run by an
  open-weight model **in the browser** (WebGPU via WebLLM, or CPU via llama.cpp/WebAssembly). Prompts and answers never leave the phone.
- **AI guardrails** (`src/ai/guard.ts`, `src/engine/word-problems/validate.ts`) — code re-checks every AI reply; wrong numbers,
  invented operations or English-only answers in Taglish mode are replaced by the calculator's verified explanation.
- **Games** — Tagisan ng Talino (duel), Sari-Sari Store Cashier, Sipnayan Nerdle (daily puzzle).
- **Pipo's voice-overs** — 23 voice-over lines, cached with the app.
- **Assessment reports** — PDFs are drawn on the device (jsPDF) and shared through the phone's share sheet.
- **Progress** — XP, streak, badges and per-topic history stay in the browser's storage on the device; backups are a
  text code the learner copies themselves.

## What requires internet

| When | Why | Where it connects |
|---|---|---|
| First visit (and when an update exists) | Download and cache the app itself (PWA) | GitHub Pages |
| Turning on Pipo AI — **once** | Download the AI model (≈0.4–1 GB), then it is stored in the browser | Hugging Face (`mlc-ai/…-MLC` models, `Qwen/Qwen2.5-0.5B-Instruct-GGUF`) and GitHub (`mlc-ai/binary-mlc-llm-libs`, WebGPU model libraries) |
| Read-aloud of explanations (optional) | Uses the device's built-in speech voices (Web Speech API). Some browser voices are online-only (e.g. Chrome's "Google" voices); offline it only works with an on-device voice | The browser's speech service, if that voice is online-only |
| Sharing a report (optional) | The PDF is made offline; sending it uses whatever app you share to | The app you pick (Messenger, Gmail, …) |

Nothing else goes online: **no accounts, no backend, no analytics, no paid APIs.**

## The disclosures

### Models used

| Model | Used for | How it runs | License |
|---|---|---|---|
| **Qwen2.5-1.5B-Instruct** (`q4f16_1-MLC`) — "Pipo Smart" | Tutor chat, hints, "Bakit mali?", and *Kwento ni Pipo* word-problem stories | On-device, WebGPU (WebLLM) | Apache 2.0 |
| **Qwen2.5-0.5B-Instruct** (`q4f16_1-MLC`) — "Pipo Lite" | Tutor chat, hints, "Bakit mali?" on lighter devices | On-device, WebGPU (WebLLM) | Apache 2.0 |
| **Qwen2.5-0.5B-Instruct** (`GGUF Q4_K_M`) — "Pipo CPU" | Same, for browsers without WebGPU | On-device, CPU (wllama / llama.cpp WebAssembly) | Apache 2.0 |

How the AI is kept honest — *code computes, AI explains*:
- The AI never decides a number or an answer. The calculator and the question generators compute them; the AI only explains or retells.
- **Kwento ni Pipo:** the math (numbers, answer, solution) comes from code; the AI only retells a code-written story, and code checks
  the result (same numbers in the same order, units, no answer leak, real Taglish words, not a copy) before it gets the
  "Kwento ni Pipo" badge. What is and isn't checked is written down in `src/engine/word-problems/validate.ts`.
  Current status: only the sari-sari "sukli" (change) problems exist, and stories are only written by the 1.5B WebGPU model —
  on other devices the code-written story is shown without the badge.
- In testing, the 0.5B models produced unusable Taglish stories, so they are not used for stories. Pipo Smart (1.5B) needs a GPU
  with enough memory (≈1 GB+); on a laptop with a small integrated GPU it can fail to run — choose **Pipo Lite** there.

## 1. Subukan agad (walang install)

Buksan ang link sa itaas sa **Chrome** (Android / laptop) o **Safari** (iPhone). Gumagana na agad ang lessons, keyboard, calculator at mga laro.

## 2. I-install sa phone (parang app)

Ang Sipnayan ay isang **PWA** — puwedeng i-install sa home screen at gumagana kahit offline pagkatapos ng unang bukas.

**Android (Chrome)**
1. Buksan ang https://yurialfrance.github.io/TeamOryi/ sa Chrome.
2. I-tap ang **⋮** (menu, kanang itaas) → **Add to Home screen** / **Install app**.
3. I-tap ang **Install**. Lalabas ang Sipnayan icon sa home screen.

**iPhone / iPad (Safari)**
1. Buksan ang link sa **Safari** (hindi Chrome).
2. I-tap ang **Share** button (kahon na may pataas na arrow).
3. Piliin ang **Add to Home Screen** → **Add**.

> Tip: Buksan muna ang app nang isang beses habang may internet para ma-save lahat. Pagkatapos noon, puwede na kahit naka-airplane mode.

## 3. I-on ang offline AI ni Pipo (optional)

1. Sa app, pumunta sa **Ako → Offline AI** (o sa huling step ng onboarding).
2. Piliin ang **Pipo Smart (≈1 GB)** para sa laptop / phone na may malakas na GPU, o **Pipo Lite (≈0.4 GB)** para sa mas mahinang device.
3. I-tap ang **I-download ang AI** at hintayin ang progress bar. Isang beses lang ito — naka-save na sa browser pagkatapos.

Kailangan ng browser na may **WebGPU** para sa Smart at Lite (bagong Chrome o Edge sa laptop, at maraming bagong Android phones).
Kung walang WebGPU, puwede ang **Pipo CPU** (mas mabagal), at gumagana pa rin ang buong app kahit walang AI: gagamit si Pipo ng
built-in na hints at ng step-by-step na sagot ng calculator.

## 4. Patakbuhin sa sariling computer (para sa developers)

**Kailangan:** [Node.js](https://nodejs.org) **v20 o mas bago** at [Git](https://git-scm.com).

```bash
git clone https://github.com/yurialfrance/TeamOryi.git
cd TeamOryi
npm install
npm run dev
```

Buksan ang **http://localhost:5173** sa Chrome.

Iba pang commands:

```bash
npm run build     # production build → dist/
npm run preview   # i-serve ang build (http://localhost:4173)
npm test          # self-tests: 24,000+ generated questions, solver, calculus, guardrails, games, reports, word problems
npm run cap:icons # Android/iOS app icons (pagkatapos ng `npx cap add android`)
```

**Subukan sa phone habang nagde-develop (same Wi-Fi):**

```bash
npm run dev -- --host
```

Buksan sa phone ang `http://<IP ng laptop>:5173` (makikita ang IP sa terminal, hal. `http://192.168.1.5:5173`).
Note: sa ganitong `http://` na link, **hindi gagana ang offline AI at ang Install** — kailangan ng `https`. Para doon, gamitin ang live link (GitHub Pages).

## 5. Paano nade-deploy ang live link

Bawat `git push` sa `main` ay automatic na nagbi-build at nagde-deploy sa GitHub Pages (`.github/workflows/deploy.yml`).

Unang setup (isang beses lang): sa GitHub repo → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Makikita ang progress sa **Actions** tab. Pagkatapos ng ~2 minuto, live na sa https://yurialfrance.github.io/TeamOryi/.

### Troubleshooting

| Problema | Solusyon |
|---|---|
| `npm` not found | I-install ang Node.js v20+, tapos isara at buksan ulit ang terminal |
| Blangko ang page sa live link | Tingnan kung green ang workflow sa **Actions** tab, at naka-set ang Pages source sa **GitHub Actions** |
| Lumang version pa rin ang nakikita | I-close at buksan ulit ang app (auto-update ang PWA), o i-refresh nang 2 beses |
| "Walang WebGPU" | Gamitin ang bagong Chrome/Edge sa laptop, o piliin ang **Pipo CPU**; gumagana pa rin ang app kahit wala nito |
| Hindi sumasagot ang Pipo Smart sa laptop | Maliit ang GPU memory (hal. integrated graphics) — piliin ang **Pipo Lite** |
| Mabagal ang AI download | ≈1 GB ito — gumamit ng Wi-Fi, o piliin ang **Pipo Lite** |

## Features

- **Landas (learning path)** — 16 islands, 125 stages: **one island per grade, Grade 1–10** (DepEd MATATAG sequence) plus SHS and
  college sampler islands (General Math, Statistics & Probability, STEM Pre-Calculus & Basic Calculus, CHED Mathematics in the Modern World).
  Every island is open; stages unlock in order. Treasure chests, trophies, and a "Matuto muna" guide card before each stage.
- **Question types** — multiple choice, typed math, tap-to-build tiles, number line, Pizza Chef, with clocks, bar graphs, tables,
  right triangles and polygons drawn by code.
- **Kwento ni Pipo** — local word problems (sari-sari store sukli) whose story is written by the on-device AI and checked by code.
- **Tutor si Pipo** — chat with the Sipnayan Calculator (verified step-by-step solutions, graphs, calculus), Taglish or English.
- **Games** — Tagisan ng Talino (2-player on one phone, or vs Pipo Bot, adaptive difficulty by grade band),
  Sari-Sari Store Cashier (sukli with real peso art, 3 levels incl. sentimo), Sipnayan Nerdle (daily math puzzle).
- **Assessment Report (PDF)** — for parents and teachers: per-topic accuracy, speed, malakas/mahina, recommendations, grade mastery and trend.
- **Game loop** — XP, daily goal, streak, hearts, gems, combo counter, daily quests, 21 badges.
- **Pipo's voice** — 23 voice-over lines on key moments; optional read-aloud of explanations.
- **PWA + Android** — installable, works offline; Capacitor project for the APK.

### Design principle: *code computes, AI explains*

Small on-device models can make arithmetic mistakes, so every lesson problem is generated by code and **graded by code**.
In the **Tutor**, every math problem goes through the **Sipnayan Calculator** first (`src/engine/solver.ts`), shown in a "verified" card.
Pipo only explains those steps; the code re-checks every number and operation the AI wrote (`src/ai/guard.ts`) and falls back to the
calculator's own explanation if anything is off — including replies in the wrong language.
